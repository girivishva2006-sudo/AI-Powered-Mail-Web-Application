# Screenshots Guide

To complete the README, take these screenshots:

## Required Screenshots

### 1. Login Screen (`login.png`)
- Visit `/` in your browser
- Capture the login page with Google sign-in button

### 2. Main Inbox View (`inbox.png`)
- Log in or use demo mode at `/demo`
- Capture the full inbox with emails listed

### 3. AI Assistant (`assistant.png`)
- Open the AI assistant panel
- Show a conversation with tool calls executing

### 4. Dark Mode (`dark-mode.png`)
- Toggle dark mode
- Capture the inbox or email view

### 5. Demo Mode (`demo.png`)
- Visit `/demo`
- Capture the demo mode header showing "Demo Mode" badge

## How to Take Screenshots

### Windows
- Press `Win + Shift + S` for Snipping Tool
- Or `PrtScn` for full screen

### Mac
- `Cmd + Shift + 4` for selection
- `Cmd + Shift + 3` for full screen

### Browser Extensions
- [GoFullPage](https://chrome.google.com/webstore/detail/gofullpage/fdpohaocaechififmbbbbbknoalclacl) - Full page screenshots
- [Lightshot](https://chrome.google.com/webstore/detail/lightshot) - Quick screenshots

## Screenshot Tips

1. Use a clean browser window (no extensions visible)
2. Set browser to 1280x800 or 1920x1080
3. Capture just the app, not the full browser
4. Use consistent lighting (dark/light mode)
5. Show real content (not empty states)

## Naming Convention

Save screenshots in the `screenshots/` folder:
```
screenshots/
├── login.png
├── inbox.png
├── assistant.png
├── dark-mode.png
└── demo.png
```
